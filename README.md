### bbocapstone

Capstone Project Overview

This repository documents my capstone project for the Professional Certificate in Machine Learning and Artificial Intelligence. The project focuses on applying machine learning techniques to a Black-Box Optimisation (BBO) challenge, where the underlying functions and evaluation criteria are hidden.

The objective is to improve performance through iterative experimentation and evidence-based decision-making. Throughout the project, I explore different approaches, analyse the results of each query, and use those findings to guide subsequent experiments.

The capstone is structured in two stages:

* Stage 1 – Practice: Exploring core machine learning techniques through guided exercises and independent experimentation.
* Stage 2 – Implementation: Applying these skills to a fixed black-box optimisation challenge, iteratively refining my approach without visibility into the underlying function or exact evaluation metrics.

This repository serves as a record of my methodology, experiments, results and reflections, demonstrating a structured approach to solving an ML optimisation problem under uncertainty.
